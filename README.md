# Bootcamp Full Stack

Repositorio con ejercicios, prácticas y proyectos desarrollados durante el Bootcamp Full Stack.

El objetivo del repositorio es registrar la evolución del aprendizaje en desarrollo web, comenzando por HTML y CSS, incorporando control de versiones con Git y GitHub, y avanzando progresivamente hacia JavaScript y otras tecnologías del desarrollo Full Stack.

## Contenido

### Ejercicios de HTML

Prácticas realizadas durante el curso para trabajar conceptos como:

- Estructura básica de documentos HTML.
- Encabezados, párrafos y listas.
- Enlaces e imágenes.
- Formularios.
- Tablas.
- Elementos semánticos.
- Organización y navegación entre páginas.

### CSS

Ejercicios enfocados en:

- Selectores y propiedades CSS.
- Colores, tipografías y estilos.
- Márgenes, padding y bordes.
- Flexbox.
- Organización de hojas de estilo.
- Diseño y presentación de páginas web.

### Landing Page

Proyecto de práctica para construir una página web utilizando HTML y CSS, aplicando estructura, estilos y organización de archivos.

### Proyecto `pag_perfil`

Proyecto de perfil de usuario compuesto por varias páginas relacionadas entre sí.

Incluye:

- Página principal del perfil.
- Edición de datos del perfil.
- Página de conexiones.
- Navegación entre las distintas vistas.
- Organización separada de HTML, CSS e imágenes.

Estructura principal:

```text
pag_perfil/
├── index.html
├── css/
│   └── style_pag_perfil.css
├── images/
└── pages/
    ├── perfil.html
    ├── editar_perfil.html
    └── conexiones.html
```

## Tecnologías utilizadas

- HTML5

- Visual Studio Code
- Git
- GitHub

## Próximos contenidos

El repositorio continuará incorporando nuevas tecnologías a medida que avance el Bootcamp, incluyendo JavaScript y herramientas asociadas al desarrollo Full Stack.

Este repositorio utiliza Git para mantener un historial de los cambios realizados durante el desarrollo y GitHub para almacenar y respaldar el proyecto de forma remota.
